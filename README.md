# 🤖 NR INVITE

> Advanced Discord Invitation System

NR INVITE es un sistema avanzado de invitaciones para Discord con tracking, estadísticas, leaderboard, configuración desde Dashboard, soporte web y panel especial.

---

## ✨ Características

- 🔗 Tracking avanzado de invitaciones
- 📊 Estadísticas de invitaciones
- 🏆 Leaderboard
- 🎉 Mensajes personalizados de bienvenida
- 🚪 Sistema de salidas
- 🎁 Rol por invitación
- 📜 Sistema de logs
- 🖥️ Dashboard web
- 🔐 Inicio de sesión con Discord
- 🏰 Gestión de servidores
- 🆘 Sistema de soporte web
- 📧 Notificaciones por correo
- 📢 Sistema de anuncios
- 👑 Panel especial
- 🌐 Sistema multidioma
- 🔔 Notificaciones del Dashboard
- 🛠️ Acceso rápido al soporte
- 🔴 Estado DND permanente
- 🌐 Express compatible con Render
- 💾 Persistencia mediante archivos JSON
- 🚫 Sin SQLite

---

# 🤖 Comandos

| Comando | Descripción |
|---|---|
| `/help` | Muestra la ayuda |
| `/setup invite` | Configura las invitaciones |
| `/active invites` | Activa las invitaciones |
| `/disable invites` | Desactiva las invitaciones |
| `/invites` | Muestra tus invitaciones |
| `/invites usuario` | Consulta otro usuario |
| `/leaderboard` | Ranking de invitadores |
| `/stats` | Estadísticas del servidor |
| `/message` | Configura el mensaje |
| `/channel` | Configura el canal |
| `/leave` | Configura las salidas |
| `/role` | Configura el rol |
| `/logs` | Configura los logs |
| `/reset` | Restablece la configuración |
| `/info` | Información del bot |

# 🔗 Invite Tracking

🎉 ¡Bienvenido/a @Usuario a Mi Servidor!
